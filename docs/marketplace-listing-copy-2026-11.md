## FormFlow — overview

FormFlow helps you run lightweight approval workflows from Google Forms. Start with a leave request, purchase request, or access request: send the reviewer an email, capture approve/reject through the decision link, and track status in the linked Google Sheet.

For your first run, use a copied form and synthetic data. Link the response Sheet, add one internal approver, run Preflight, and submit one test request. Confirm the approval email arrives, the decision link works, and the linked Sheet records the result before accepting real requests.

Free includes 50 approval flow runs per month and up to 5 approval levels. Pro is $79 per admin per year, with unlimited flow runs and up to 5 levels. Choose Pro for the run-volume boundary, not because it turns FormFlow into an enterprise suite.

FormFlow is not an enterprise approval suite, procurement platform, compliance system, or ticketing tool. It is a focused email approval path with a Sheet record.

## Choice Sync — overview

Looking for a Form Ranger alternative for Google Forms choices maintained in Google Sheets? FormSuite Choice Sync focuses on careful, owner-controlled choice updates: select a source, map a question, run Preflight, inspect the exact added/removed/unchanged diff, and approve the output before Update now.

Choice Hygiene highlights duplicate and look-alike labels without rewriting your source Sheet. File access uses drive.file for selected files rather than broad Drive access. Five bounded recovery versions include live-drift checks before restore; this is not unlimited backup.

Start with one copied form, one supported question, and a Sheet column containing Alpha and Beta. After the update, check the public respondent preview, not only the form editor.

Free includes 100 syncs per month and up to 3 linked questions. Pro is $29 per year, with unlimited syncs and linked questions. Direct Pro checkout is paused; email support@formsuite.dev to confirm upgrade availability before paying. Checkout resumption is pending, not a working payment link.

Choice Sync is an independent FormSuite add-on and is not affiliated with Form Ranger. It is not live inventory locking, booking, payment processing, or respondent-time dependent dropdown filtering.
