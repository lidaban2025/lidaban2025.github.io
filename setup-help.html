Good first tests

Send a setup note for one small workflow

The clearest notes describe one add-on, one test file, and one step that blocked the first run. These workflows are a good fit for founder-led setup help.

FormGuard

Test one per-choice quota using Alpha and Beta, inspect the respondent page, and keep native Forms controls in mind for simple total caps.

FormCopy Pro

Keep response-sheet formulas, helper columns, scoring columns, or formats working when a new Google Forms submission creates a row.

FormNotifier

Send one respondent confirmation, one owner alert, or a shared-inbox notification after a Google Form submission.

DocForge / FormMerge Pro

Generate one test document from a sheet row, or send one test personalized email before moving a live workflow through the add-on.

Choice Sync (formerly FormRanger)

Sync one copied Google Form choice question from one Google Sheets column, then compare Preflight, Update now, and the public preview.

FormFlow

Route one internal Google Forms submission to one reviewer, then check Preflight, reviewer email, decision link, and linked Sheet status.

Before sending

  1. Install the add-on from Google Workspace Marketplace.
  2. Open it in the right Google app: Forms for FormGuard/FormNotifier/FormRanger/FormFlow, Sheets for FormCopy/FormMerge/DocForge.
  3. Run one small test: one cap, one email, one copied formula, one generated file, or one synced choice list.
  4. Send the add-on name, the workflow goal, and the first step that did not work.
