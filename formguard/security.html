FormGuard — Security & Privacy Overview

LidaBan Studio · formsuite.dev/formguard · Prepared for district procurement review · October 2026

Product

Google Forms™ add-on (Google Workspace Marketplace): response caps, per-option quotas, scheduled close/reopen, owner alerts.

Data collected

Quota calculations read responses through Google services. Optional paid-license checks send account email, signed license key, and product identifier to our license service, excluding form questions and responses.

Architecture and data boundaries

Configuration storageForm-bound configuration uses Google Apps Script properties. Scheduled jobs also use Google-hosted script properties for form identifiers, times, and alert settings; license state uses user/script properties and the FormSuite license service.
External callsThe updated paid build calls the FormSuite license service for entitlement validation. These calls include account email, signed license key, and product identifier, but not form questions or responses.
Response dataChoice quotas read submitted responses to count selections and update available options. These responses are not included in external license requests.
NotificationsOptional alerts are sent by the form owner's own Google account to recipients the owner chooses.

Privacy agreements & compliance

CA-NDPACalifornia Student Data Privacy Agreement v1.5 fully executed with San Bernardino City USD via CITE Privacy Services — Document Ref GMWHH-DGNBA-TUZMK-XBM4S, term through September 26, 2029. Exhibit E piggyback available to California districts.
MarketplacePublished on Google Workspace Marketplace (Google-run security review of OAuth scopes; single sign-on via district Google accounts; no separate student login).
FERPA/COPPA postureThe executed agreement governs the agreed scope. Districts should review the current permissions, data flows, and intended deployment with their privacy contact before enabling real student workflows.

Permission purposes (updated scope verification is under review)

  • Forms container UI — display the settings sidebar inside a form
  • Form service — read/update the form's acceptance setting, options, and FormGuard's own configuration properties
  • Script triggers — run scheduled close/reopen at times the form owner sets
  • Owner mail — send alerts from the form owner's own account to owner-chosen recipients

Full purpose-by-purpose list: formsuite.dev/formguard/permissions.html
