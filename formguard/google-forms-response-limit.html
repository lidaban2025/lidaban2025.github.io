Choose a native response cap or a per-option quota

For a total response limit or closing date, start with Google Forms itself. Use FormGuard when the options in one question need quotas. Neither approach guarantees an exact count during simultaneous submissions.

Quick answer

Total cap

Close the whole form.

Choose native settings when your rule is a total number of responses or one closing date.

Option quota

Remove full choices.

Use FormGuard when Alpha can fill while Beta remains available. Set one maximum per option for that question.

Storage warning

A different kind of limit.

An approaching data or response-storage limit is not a signup quota. An add-on cannot raise Google's platform limits.

Boundary

Keep the first test small.

Use a copied form and a tiny limit before applying the rule to production traffic.

Set a native Google Forms response limit

  1. Open a published form and select Published.
  2. Under Accepting responses, select Set close date or response limit.
  3. Choose a closing date or After a number of responses, then save.

Google notes that simultaneous submissions can pass the cap. See Google's current response-management instructions.

Seeing “Response limit approaching”?

Google documents separate limits of 1 GB total form storage and 500,000 responses per form from September 2026. Storage includes the form and response data, but excludes user-uploaded files. FormGuard cannot increase these limits.

Confirm the exact warning and your form's current data before changing anything. If you plan to archive or delete responses, export and verify a backup first. Read Google's data-limit guidance. A signup cap, an option quota and a storage warning need different fixes.
