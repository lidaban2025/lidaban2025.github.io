Frequently asked questions

Does Google Forms already have response limits?

Yes. Google Forms supports native closing by total response count or date and time. Use those controls for a simple cap or deadline. FormGuard adds per-choice quotas, scheduled opening, close messages, and owner alerts. Read the Google announcement.

Can it limit the choices in one question?

Yes. Set Max per option for that question; the same maximum applies to all its options. The current setting does not assign different numbers to individual choices. Already-open forms and simultaneous submissions can exceed a quota. Run a two-choice quota test before launch.

Should I test on a live form first?

No. Use a copied form with tiny quotas, then apply the same setup to the real form after it passes.
