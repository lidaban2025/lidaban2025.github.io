What this test does—and does not—prove

It proves that your copied file can reach the reviewed path: duplicate block → corrected exact preview → one-time approval → one send attempt → row and trigger inspection. It does not prove provider-level exactly-once delivery. An ambiguous provider result must remain fail-closed as SEND_UNCERTAIN:.
