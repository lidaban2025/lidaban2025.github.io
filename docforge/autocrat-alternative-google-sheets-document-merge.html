A narrow, safety-first document merge alternative

DocForge is an independent Google Sheets add-on for a simple document merge: one Google Docs template, a copied spreadsheet, explicit field mapping, one exact source-row preview, and one verified Docs or PDF output before a batch.

Copied-sheet migration test

  1. Copy the original spreadsheet and duplicate one simple Google Docs template.
  2. Use synthetic or non-sensitive data in the copied sheet.
  3. Select the copied template and scan every {{merge field}}.
  4. Map each field to one Sheet column; fix missing, duplicate, or blank headers.
  5. Run Preflight and inspect the exact values for one selected source row.
  6. Generate one Google Doc or PDF and open it.
  7. Confirm field values, file name, output type, long-text layout, and destination before any batch.

Why the one-output gate matters

A successful configuration save does not prove a document merge. The useful result is an output file that contains the expected values and layout. If a field is unmapped, a source header is duplicated, or a selected row is blank, the workflow should stop before creating a batch of incorrect files.
