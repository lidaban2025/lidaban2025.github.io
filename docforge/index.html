Frequently asked questions

Can it create PDFs?

Yes. The workflow supports generating documents and PDF-style outputs from rows.

Do I need a template?

Yes. A Google Docs template gives the generated files their structure.

Should I run all rows immediately?

No. Run Preflight, inspect one exact row preview, generate one file, and verify its fields and layout before a batch.
