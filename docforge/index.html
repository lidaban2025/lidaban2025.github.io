Questions, answered

Is this a replacement for Autocrat?

For straightforward one-template merges — certificates, letters, reports — yes, and it's simpler. DocForge doesn't try to be a full document-management or approval platform; it does one job reliably.

What if my template changes halfway through the year?

DocForge notices. Any change to the template, column headers, or file naming requires a fresh one-file proof before the next batch — so a mid-year tweak can't silently corrupt 200 files.

Can it make PDFs, or only Google Docs?

Both. Generate editable Google Docs, print-ready PDFs, or both from the same run.

What happens to rows with missing data?

They're flagged before generation, not after. Blank required fields block the safety check so you fix row 47 instead of apologizing for it.
