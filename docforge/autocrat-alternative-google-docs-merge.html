A safer Autocrat alternative for document merge

DocForge is an independent Google Sheets add-on for teams moving a simple Autocrat-style document merge: one Google Docs template, a single-file proof you inspect first, clean file naming, and re-runs that never duplicate what already worked.

Install DocForgeRun the one-file test
Not a drop-in replacement: Autocrat is a mature document merge tool with its own job model and output options. DocForge does not claim parity with complex multi-template workflows or approval chains. It covers one job: reviewed document generation where a bad batch — 200 misspelled certificates — is costly.

Autocrat-style workflow vs DocForge

The products solve overlapping but different jobs. DocForge deliberately avoids job-builder complexity and focuses on the high-cost document mistake: the batch that generated 200 wrong files.

One-file migration test

  1. Copy the original spreadsheet; keep the production Sheet untouched.
  2. Build or pick one Google Docs template with placeholders like {{Name}}.
  3. Link each placeholder to a column — once.
  4. Generate one file. Open it. Check the layout, the file name, and the destination folder.
  5. Happy with the proof? Run the batch on the copy.
  6. Review the summary: generated, reused, changed, failed.
  7. Confirm no duplicates before running on real data.

Why the proof matters for Autocrat-style migrations

The most common migration accident is the confident batch: the template looked right, the mapping looked right, and 200 files later someone notices the date format is wrong on every certificate. A single inspected file costs thirty seconds. A bad batch costs an afternoon of apologies — or a reprint budget. DocForge makes the proof a gate, not a suggestion: the batch cannot run until one file has passed your own eyes.
