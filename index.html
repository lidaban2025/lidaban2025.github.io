Short answers

FormSuite FAQ

Which FormSuite workflow should I start with?

Use FormNotifier for Google Forms owner alerts and respondent acknowledgements. Choice Sync handles spreadsheet-backed choices, FormMerge handles operational mail merge, and DocForge generates Docs or PDFs. Start with the copied-file test for your task.

Why start with a copied file?

A copied file gives you a reversible place to test permissions, mappings, preflight warnings, exact previews, and the final output without changing a live workflow.

Where do I install the add-ons?

Use each product's Google Workspace Marketplace listing, then run the first-test path shown on its FormSuite page.
